# SZU-CS-Survival-Guide
### 项目简介

大家好，我是深圳大学 2024 级计算机科学与技术专业的学生 HanYu。

作为一个从大一开始就被“绩点绑架”、被“保研绑架”、被“留学申请绑架”的计算机学生🫩，我在这几年学习过程中，也逐渐摸索出了一些关于课程学习、提高GPA以及规划未来方向的小经验📔🎓。（与此同时，我也一直在科研方面持续探索与努力中 💪）

在成长过程中，我也曾得到过许多学长学姐的帮助，他们分享的经验和资料让我少走了很多弯路。因此，我也希望成为这样的一名前辈，把自己一路走来，陆陆续续整理的学习笔记、课程资料、实验报告以及各种学习心得整理出来，分享给之后的计算机学习者。

于是，我创建了这个平台——**SZU-CS-Survival-Guide**，希望记录自己的学习历程，也为深圳大学计算机相关专业的同学提供一些参考。

这里整理了我修读过的大部分公共基础课和专业课程，可能包括：

- 课程学习经验🏫
- 选课建议🎓
- 老师评价与课堂体验👩‍🏫
- 实验报告参考📑
- 学习笔记📖
- 复习资料📚

未来也会持续更新更多内容，包括科研探索、留学申请、保研经验以及计算机方向的学习路线（也顺便借助这个项目激励我不断学习，持续为大家分享( •̀ ω •́ )✧）。

希望这些资料能够给学弟学妹们提供一点点帮助，让大家从 0 基础的 **freshman → senior** 的成长道路上，可以少走一些弯路，更加顺利地探索属于自己的计算机学习之路ヾ(≧▽≦*)o
